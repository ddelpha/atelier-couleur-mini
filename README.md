# Atelier Couleur — Mini site (€149)

Fictional French house-painter business. First of four package examples; this version is a compact static one-page website. All business details are illustrative. Contact details intentionally do not initiate calls or send mail. TEI links point to the real website provider.

Palette: cream `#f7f3ec`, charcoal `#2e332f`, terracotta `#a54f39`, sand `#e9dece`.

No build, dependencies, forms, tracking or remote font requests. Serve this directory with any static server. Mobile layout and keyboard focus supported; reduced-motion preference respected. Search indexing disabled for the demonstration.
